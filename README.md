# Признание заслуг — прототип модуля

Интерактивный прототип модуля **«Признание заслуг»** для цифрового ядра
Национального Банка Республики Казахстан. Сотрудники направляют друг другу
благодарности, модератор и администратор их согласуют, набранные баллы
формируют рейтинг и галерею победителей.

Прототип приводится к модели боевого модуля MeritRecognition (OutSystems):
ключ работника — табельный номер, пять статусов заявки, роли инициатора,
модератора, администратора и руководителя.

## Что внутри

| Файл | Назначение |
|---|---|
| `Признание заслуг.html` | сам прототип — один самодостаточный файл |
| `employees.json` | справочник сотрудников и учётные записи |
| `Рейтинг.json` | баллы и количество бейджей за год |
| `Сотрудники.xlsx`, `Рейтинг.xlsx` | исходные таблицы, из которых собираются JSON |
| `фото/`, `фото-200/` | фотографии для аватарок: оригиналы и сжатые 200×200 |
| `fix-*.ps1`, `photo200.ps1` | скрипты правки прототипа и подготовки фотографий |
| `UI Design System*.html` / `*.md` | дизайн-система: светлая и тёмная темы |
| `доп варианты/` | ранние версии прототипа |

## Технологии

- **React 19** — вшит в файл вместе с приложением, сборка не требуется
- **Обычные HTML, CSS и JavaScript** — ни `package.json`, ни зависимостей
- **JSON** — справочник сотрудников и рейтинг, подгружаются при старте
- **PowerShell + System.Drawing** — правки прототипа и обработка фотографий
- **localStorage** — рабочее состояние: заявки, согласования, остатки баллов

## Как запустить

Прототип открывается двойным кликом по `Признание заслуг.html`, но тогда он
работает на встроенных демонстрационных данных: браузер запрещает читать
соседние файлы с диска.

Чтобы подгрузились `employees.json` и `Рейтинг.json`, нужен локальный сервер:

```
cd "путь к папке проекта"
python -m http.server 8010
```

Затем открыть <http://localhost:8010/Признание%20заслуг.html>

Признак того, что данные подхватились, — строка в консоли браузера (F12):

```
employees.json: 24 people, 4 users; Рейтинг.json: 22 записей
```

Если вместо неё написано `встроенные данные` — сервер не запущен либо файл
не найден, приложение поднялось на резервных данных и показывает плашку
демонстрационного режима.

## Учётные записи прототипа

Демонстрационные, пароль у всех `12345`, подставляется автоматически:

| Логин | Роль |
|---|---|
| `CORP.NB.RK\1` | инициатор |
| `CORP.NB.RK\2` | администратор |
| `CORP.NB.RK\3` | модератор |
| `CORP.NB.RK\4` | руководитель |

## Как править данные

Правится только `Сотрудники.xlsx` — `employees.json` собирается из него.
Ручные правки в JSON затрутся при следующей перегенерации.
