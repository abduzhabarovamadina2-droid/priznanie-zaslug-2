# Утилиты администратора

Разовые скрипты для работы с базой. Запускаются из папки `backend`,
берут подключение из `backend/.env`:

```powershell
cd backend
node tools/list-users.js
node tools/reset-password.js
```

| Скрипт | Что делает |
|---|---|
| `list-users.js` | список учётных записей |
| `check-users.js` | состав таблицы пользователей |
| `check-password.js` | сверка пароля с хешем |
| `reset-password.js` | сброс пароля учётной записи |
| `update-password.js` | смена пароля учётной записи |
| `check-encoding.js` | проверка кириллицы в подключении к БД |

В рабочем контуре пароли меняются только этими скриптами — руками хеши
в таблицу не пишем.
