UI Design System — «Признание заслуг»

Цифровое ядро НБРК · тема nbrk-emerald · обе темы в одном файле, переключатель в шапке

1.1 Цветовая палитра

Основа — изумрудная шкала. Семантика всегда применяется триадой: base (точка/иконка), soft (подложка 10 %), text (подпись). Цветом одним смысл не передаётся.

1.2 Типографика

Inter для заголовков и текста, системный моно — для номеров заявок и БИН. Веса только 500 / 600 / 700 / 800. Полушаги вроде 12.5 px из исходного макета сведены к целым ступеням.

1.3 Отступы, сетка, брейкпойнты

Базовый шаг — 4 px. Контейнер 1600 px, сайдбар 260 → 76 px, правая колонка 330 px.

1.4 Скругления и границы

Границы: 1 px — базовая · 1.5 px — акцентная на цветной подложке · 2 px — кольцо аватара и медали · 1 px dashed — пустые состояния.

1.5 Тени и размытие

Blur: surface 24 px (только тёмная тема) · bar 10 px · dock 20 px + saturate(1.1) · scrim 5 px · modal 28 px · glass 14 px + saturate(1.1).
Фокус: 0 0 0 3px rgba(20,162,96,.35) · Ошибка: 0 0 0 3px rgba(239,68,68,.18)

2.9 Кнопки действий процесса

Цвет кнопки кодирует смысл действия в маршруте согласования. На экране одновременно — только действия, доступные текущей роли и статусу. Подпись — глагол.

Семантика действия
Неактивное состояние
Функциональные действия
Палитра действий
approve — согласование delegate rework — доработка neutral reject — отказ danger — отозвать/удалить
DoОдно первичное действие маршрута — зелёное. Необратимое (отозвать, удалить) — красное. Отказ и запрос срока — тёмное. Возврат на доработку — оранжевое.
Don'tНе красить «Отклонить» в зелёное, «Удалить» — в нейтральное. Не показывать действия, недоступные роли и статусу заявки.

2.10 Система статусов

Статус = цветная точка + текст, всегда парой. Цвет — по семье этапа: успех, отправка, согласование, подписание, доработка, отказ. Один и тот же цвет — один смысл во всём модуле.

Don'tНе заводить отдельный цвет под каждый статус — глаз перестаёт их различать. Не передавать статус только цветом без подписи.

Пункт: [иконка?] [подпись] [галочка / шеврон?]. Три состояния: обычное, наведение, выбранное. Высота 36 px, радиус 8 px.

Выбранное
DoВыбранный пункт — подложка accent-soft + цвет акцента. Заголовок группы — капсом, без интерактива.
Don'tНе смешивать пункты с галочкой (множественный выбор) и с шевроном (переход) в одном списке.
