**Версия:** 1.0 · **Кодовое имя темы:** `nbrk-emerald-light` · **Источник:** рабочий прототип
`Признание заслуг.html`.

> расходятся поверхности, границы, тени, семантические ступени текста и работа `backdrop-filter`.

**Поправка на светлую тему.** Тёмный текст на светлом фоне читается «тоньше», чем светлый на
тёмном. Поэтому в светлой теме:

- вес `500` — минимальный для основного текста; вес `400` не применять вообще;
- `display 46/300` допустим только на тёмном градиентном фоне (виджет погоды) — на белом
  такой тонкий контур выглядит бледно, там берётся `metric 30/800`;
- белая подпись на фирменном градиенте — от **14 px / 700** (см. §1.8).

## 1.3. Сетка и отступы

**Базовый шаг — 4 px.**

| Токен | px | Типичное применение |
|---|---|---|
| `space-0.5` | 2 | зазор между иконкой и точкой статуса |
| `space-1` | 4 | внутренний зазор чипа |
| `space-1.5` | 6 | иконка + подпись в кнопке |
| `space-2` | 8 | зазор между кнопками, поля таблицы |
| `space-2.5` | 10 | иконка + текст в пункте меню |
| `space-3` | 12 | горизонтальный padding кнопки, gap форм |
| `space-3.5` | 14 | padding ячеек таблицы (верт.) |
| `space-4` | 16 | gap сеток, padding компактных карточек |
| `space-5` | 20 | padding карточки (`.pad`), gap KPI-сетки |
| `space-6` | 24 | padding страницы и модалок |

**Контейнер:** `max-width: 1600px`, `padding: 24px`, `margin: 0 auto`.
**Сайдбар:** `260px` → `76px` в свёрнутом состоянии.
**Правая колонка главной:** `330px`, `position: sticky; top: 12px`.

| Breakpoint | min-width | Раскладка |
|---|---|---|
| `base` | 0 | одна колонка, фильтры вертикально |
| `sm` | 640 px | плитки в 2 колонки |
| `md` | 820 px | сетки 2–3 колонки, пьедестал горизонтально |
| `lg` | 1100 px | фильтры в ряд, таблицы без переносов |
| `xl` | 1250 px | главная в 2 колонки со sticky-рейлом |
| `2xl` | 1600 px | контейнер достигает максимума |

**Правило:** широкие таблицы всегда скроллятся внутри `overflow-x:auto`; горизонтального
скролла у страницы быть не должно ни на одном брейкпойнте.

**Поправка на светлую тему.** Соседние карточки на светлом фоне сливаются сильнее, чем на
тёмном: `--color-surface #fff` и `--color-bg #f2f6f3` различаются слабо. Поэтому зазор между
карточками в светлой теме — **не меньше `space-4` (16 px)**, и каждая карточка обязана иметь
границу `1px --color-line`. В тёмной теме зазор 12 px допустим, потому что слои разделяет тень.

## 1.4. Тени и эффекты

| Токен | Значение | Где в светлой теме |
|---|---|---|
| `shadow-xs` | `0 1px 2px rgba(18,40,32,.05)` | **базовая тень карточки** |
| `shadow-sm` | `0 2px 8px rgba(16,185,129,.30)` | активная пилюля |
| `shadow-md` | `0 12px 28px -12px rgba(0,0,0,.25)` | hover карточки/KPI |
| `shadow-lg` | `0 20px 40px -12px rgba(0,0,0,.35)` | выпадающие панели |
| `shadow-xl` | `0 24px 48px -20px rgba(0,0,0,.55)` | панель уведомлений |
| `shadow-2xl` | `0 40px 90px -30px rgba(0,0,0,.70)` | модальные окна |
| `shadow-card-dark` | `0 0 0 1px rgba(16,185,129,.05), 0 24px 60px -24px rgba(0,0,0,.7)` | **не применяется** — только тёмная тема |
| `shadow-action` | `0 6px 18px -6px rgba(16,185,129,.70)` | primary-кнопка действия |
| `glow-brand` | `0 0 18px 3px rgba(20,220,140,.35)` | пульсация логотипа |

**Правило уровней в светлой теме.** Тяжёлые уровни (`xl`, `2xl`) допустимы только для
всплывающих слоёв — модалок, выпадающих панелей, тултипов. На карточках и плитках максимум —
`shadow-xs` в покое и `shadow-md` на hover. Тёмная тень под статичным блоком на светлом фоне
читается как грязь.

**Blur / Backdrop**

| Токен | Значение | Где в светлой теме |
|---|---|---|
| `blur-surface` | **`none`** (в тёмной — `blur(24px)`) | карточки: размытие выключено |
| `blur-bar` | `blur(10px)` | верхняя «таблетка» — работает, фон под ней градиентный |
| `blur-dock` | `blur(20px) saturate(1.1)` | прилипшая шапка |
| `blur-scrim` | `blur(5px)` | подложка модалки |
| `blur-modal` | `blur(28px)` | само модальное окно |
| `blur-glass` | `blur(14px) saturate(1.1)` | стеклянный виджет погоды (остаётся тёмным) |

**Фокус:** `border-color: var(--color-primary-500)` + `box-shadow: 0 0 0 3px rgba(20,162,96,.35)`.
**Ошибка:** `border-color: #ef4444` + `box-shadow: 0 0 0 3px rgba(239,68,68,.18)`.
Оба кольца рассчитаны на светлый фон и в тёмной теме не меняются.

## 1.5. Скругления и границы

| Токен | px | Применение |
|---|---|---|
| `radius-xs` | 4 | чипы, клавиши, заливки шкал |
| `radius-sm` | 8 | кнопки, поля поиска, иконки-плашки |
| `radius-md` | 12 | поля форм, вложенные карточки, пункты меню |
| `radius-lg` | 16 | карточки, модалки, таблицы |
| `radius-xl` | 22 | стеклянные виджеты |
| `radius-full` | 999 | пилюли, статусы, аватары, верхняя панель |

**Границы:** толщина **1 px** — базовая (`--color-line`); **1.5 px** — акцентная обводка на
цветных подложках; **2 px** — кольцо вокруг аватара/медали; **1 px dashed** — пустые состояния.

**В светлой теме граница — главный инструмент разделения слоёв**, а не тень. Правила:

- любая карточка, таблица, поле и выпадающая панель имеют видимую границу `1px --color-line`;
- граница не заменяется на `transparent` при hover — меняется только фон (`--color-row-hover`);
- вложенный блок (`card-soft`) берёт `--color-line-soft`, чтобы не спорить с внешней границей.

## 1.6. Движение

| Токен | Значение | Применение |
|---|---|---|
| `duration-fast` | 180 ms | появление поповеров, `scaleIn` |
| `duration-base` | 220 ms | hover, смена цвета/фона |
| `duration-slow` | 350 ms | `fadeIn`, смена темы |
| `duration-entrance` | 500 ms | каскадное появление карточек |
| `ease-standard` | `ease` | микровзаимодействия |
| `ease-entrance` | `cubic-bezier(.22,1,.36,1)` | появление, рост шкал |
| `ease-overlay` | `cubic-bezier(.16,1,.3,1)` | модалки, drawer |
| `stagger` | 60–80 ms × index | каскад в сетках и списках |

Именованные keyframes: `fadeIn`, `scaleIn`, `slideIn`, `modalIn`, `winIn`, `growBar`,
`navSheen` (6 s), `navBreathe` (4.5 s), `pulseSoft` (1.8 s), `haloSpin` (6 s), `sunSpin` (14 s).

**Обязательно:** весь декоративный моушен выключается в `@media (prefers-reduced-motion: reduce)`.
**Запрет:** не анимировать `width`/`height` у элементов внутри контейнеров с `backdrop-filter` —
использовать `transform` (иначе слой не перерисовывается).

**Поправка на светлую тему.** Анимации прозрачности (`breathe`, `pulseSoft`) на светлом фоне
почти не читаются: элемент уходит не «в темноту», а в белое. Для светлой темы декоративная
пульсация выполняется через `transform: scale()` или смену насыщенности, а нижняя граница
`opacity` поднимается с `.45` до `.65`.

## 1.7. Особенности светлой темы — сводка

| Аспект | Светлая | Тёмная |
|---|---|---|
| **Поверхности** | плотные, `#fff`, `backdrop-filter: none` | полупрозрачные, работают в паре с `blur(24px)` |
| **Разделение слоёв** | границы `1px` — главный инструмент | тени и свечения; границы почти невидимы |
| **Тени** | лёгкие: базовая `0 1px 2px rgba(18,40,32,.05)` | глубокие: `0 24px 60px -24px rgba(0,0,0,.7)` |
| **Тяжёлые уровни** | только модалки и выпадающие панели | допустимы и на карточках |
| **Семантический текст** | тёмные ступени: `#059669`, `#d97706`, `#dc2626`, `#0284c7` | светлые: `#34d399`, `#fbbf24`, `#f87171`, `#38bdf8` |
| **Фирменный градиент** | без изменений, текст на нём всегда белый | без изменений |
| **Стеклянные виджеты** | остаются тёмными — работают как акцентный блок на светлом фоне | сливаются с фоном страницы |
| **Поля ввода** | фон `rgba(242,246,243,.82)`, граница `#e3ebe6` | фон `rgba(20,35,29,.64)`, граница `rgba(52,211,153,.15)` |
| **Медали / бейджи** | ступень `-100` только с обводкой `-500` | ступень `-100` работает как есть |
| **Минимальный вес текста** | 500 | 500, но 400 визуально допустим |
| **Зазор между карточками** | от 16 px | от 12 px |
| **Пульсация** | через `scale`, нижняя `opacity` .65 | через `opacity` до .45 |

### Что переносится без изменений

Шкала типографики, шкала отступов, радиусы, брейкпойнты, длительности и кривые, фирменный и
наградный градиенты, вся анатомия компонентов §2, семантические `base` и `soft`, фокус-кольцо
и кольцо ошибки.

### Что нельзя делать в светлой теме

1. Не выводить `--color-primary-300 #34d399` текстом на белом — это тёмнотемная ступень,
   на `#fff` даёт ~1.8:1.
2. Не заменять границу тенью «чтобы было чище» — на светлом фоне слои перестают различаться.
3. Не использовать `shadow-2xl` под статичной карточкой.
4. Не включать `backdrop-filter` на карточках — размывать нечего, а компоновка слоёв ломается
   (см. запрет на анимацию `width` в §1.6).
5. Не осветлять фирменный градиент под светлую тему — он опознавательный знак бренда и остаётся
   тёмным в обеих темах.

## 1.8. Контраст (WCAG 2.1) — измеренные значения

# 2. CORE UI COMPONENTS

Анатомия, размеры, состояния и правила компонентов идентичны тёмной редакции. Ниже отмечено
только то, что в светлой теме выглядит или ведёт себя иначе — помечено **[Светлая]**.

## 2.1. Button

**Анатомия:** `[иконка 14–16] [подпись] [бейдж-счётчик?]`, `display:flex`, `gap: space-1.5`,
`border-radius: radius-sm`, `font: body-sm/600`.

**Варианты**

| Вариант | Фон | Текст | Граница | Тень |
|---|---|---|---|---|
| `default` (secondary) | прозрачный | `text-muted` | `1px var(--color-line)` | нет |
| `primary` | `linear-gradient(90deg,#10b981,#0d4530)` | `#fff` | нет | `0 4px 12px rgba(16,185,129,.3)` |
| `action` (крупная в модалках) | `linear-gradient(100deg,#14a260,#0d4530)` | `#fff` | нет | `shadow-action` |
| `ghost` | прозрачный | `text-muted` | `1px var(--color-line)` | нет |
| `destructive` | `var(--color-error-soft)` | `#dc2626` | `1px rgba(239,68,68,.3)` | нет |
| `icon` | как default | — | — | квадрат `size × size` |
| `glass` (на градиенте) | `rgba(255,255,255,.16)` | `#fff` | `1px rgba(255,255,255,.28)` | нет |

**[Светлая]** У `default` и `ghost` граница обязательна — без неё кнопка на белом фоне
превращается в текстовую ссылку. Вариант `glass` применяется **только** поверх фирменного
градиента; на белом фоне полупрозрачный белый фон невидим.

**Размеры**

| Size | height | padding-x | font |
|---|---|---|---|
| `sm` | 32 px | 12 px | 12 px |
| `md` (default) | 36 px | 12 px (primary — 14) | 12 px |
| `lg` | 42 px | 20 px | 13 px |

**[Светлая]** Подпись `primary`/`action` — белая на `#14a260` (3.30:1). Для размера `sm`
с шрифтом 12 px этого недостаточно: либо вес 700 и размер от 14 px, либо фон `#0f7f4b` (§1.8).

**Состояния**

| Состояние | Поведение |
|---|---|
| `hover` | default → `background: var(--color-row-hover)`; primary/action → `filter: brightness(1.1…1.14)`; glass → `background: rgba(255,255,255,.26)` + `translateY(-1px)` |
| `active` | `transform: scale(.96)` |
| `focus-visible` | `outline: none` + `box-shadow: 0 0 0 3px var(--ring-focus)` |
| `disabled` | `opacity:.4`, `cursor:not-allowed`, hover-эффекты отключены |
| `loading` | подпись сохраняется, иконка заменяется спиннером 14 px, `pointer-events:none`, `opacity:.7` |

**[Светлая]** `disabled` при `opacity:.4` на белом почти пропадает. В светлой теме брать
`opacity:.55` и сохранять границу на полной непрозрачности.

**Do's:** одна `primary`-кнопка на экран; деструктивные действия — только `destructive`;
в подвале модалки порядок «отмена слева → подтверждение справа».
**Don'ts:** не ставить рядом две `primary`; не использовать `destructive` для «Отмены» формы
(это `ghost`); не делать кнопку шире 320 px, кроме полноширинных в модалках входа.

## 2.2. Input / Select / Textarea

**Анатомия:** `label` (12 px/700, `text-muted`, отступ снизу 8 px) → `control` →
`hint | errmsg` (11 px/600).

| Тип | height | padding | radius | Особенности |
|---|---|---|---|---|
| `text` / `select` | 46 px | 0 14 px | `radius-md` | select — `cursor:pointer` |
| `textarea` | min 104 px | 12 14 px | `radius-md` | `resize: vertical`, `line-height 1.55` |
| `search` (в шапке) | 36 px | 0 64 px 0 36 px | `radius-sm` | иконка слева, `kbd`-подсказка справа |
| `mini-search` (в таблицах) | 32 px | 0 12 px 0 30 px | `radius-sm` | ширина 224 px |
| `filter-select` | 34 px | 0 10 px | `radius-sm` | над таблицами |

Фон `--color-field` `rgba(242,246,243,.82)`, граница `--color-field-line` `#e3ebe6`,
текст `--color-text`, плейсхолдер `--color-text-faint`.

**[Светлая]** Поле светлее фона страницы всего на несколько процентов — граница здесь несёт
всю нагрузку и не должна пропадать ни в одном состоянии. Плейсхолдер `--color-text-faint`
даёт 2.64:1: он допустим как подсказка формата, но **не** как единственный носитель смысла —
подпись поля обязательна.

**Состояния:** `hover` — граница `--color-line` → чуть контрастнее · `focus` — фокус-кольцо ·
`error` — красная граница + красное кольцо + `.errmsg` под полем · `disabled` — `opacity:.55`,
`cursor:not-allowed` · `readonly` — цвет текста `--color-text-muted`, `cursor:default`, фон без изменений.

**Do's:** обязательные поля помечать `*` в подписи; счётчик символов у полей с лимитом
(`0/250`, `0/500`); зависимые селекты блокировать с поясняющим текстом
(«Сначала выберите номинацию»).
**Don'ts:** не выводить ошибку до первого взаимодействия; не прятать подпись в плейсхолдер.

## 2.3. Card

| Вариант | Фон | Граница | Радиус | Тень |
|---|---|---|---|---|
| `card` | `--color-surface` `#fff` | `1px --color-line` | `radius-lg` | `shadow-xs` |
| `card-soft` | `--color-surface-2` `#f7faf8` | `1px --color-line-soft` | `radius-md` | нет |
| `table-card` | как `card`, `overflow:hidden` | — | `radius-lg` | — |
| `stat` (KPI) | как `card`, `padding: space-5` | — | `radius-lg` | hover: `translateY(-2px)` + `shadow-md` |
| `gradient-header card` | шапка — фирменный градиент, тело — `#fff` | — | `radius-lg`, `overflow:hidden` | — |
| `glass` | тёмная база + размытые цветные пятна + `blur-glass` | `1px rgba(255,255,255,.10)` | `radius-xl` | `0 24px 50px -26px rgba(0,0,0,.95)` |

**Анатомия карточки с шапкой:** `header` (иконка + заголовок 15/700 + действие справа) →
`sub` (маркер-точка + подпись 12/700 + чип-счётчик) → `body` (`padding: space-4 space-5`).

**[Светлая]** `card` и `card-soft` различаются лишь на 3 % яркости — вложенность читается
за счёт радиуса и границы, а не фона. Вариант `glass` остаётся тёмным: на светлой странице он
работает как акцентный остров, и это единственный компонент, сохраняющий тёмную подачу в обеих
темах. `gradient-header card` — второй такой островок.

**Do's:** одна карточка = одна смысловая единица; действия карточки — в её шапке справа.
**Don'ts:** не вкладывать `card` в `card` (для вложенности — `card-soft`); не смешивать
`glass`-вариант с обычными в одной колонке без визуальной паузы; **[Светлая]** не ставить
рядом больше двух тёмных островков — страница начинает выглядеть «дырявой».

## 2.4. Modal

**Анатомия:** `overlay` (`position:fixed; inset:0; z-index:60; padding:24px`, центрирование) →
`scrim` (`--color-scrim` + `blur-scrim`) → `dialog`.

| Размер | max-width |
|---|---|
| `md` (default) | 560 px |
| `lg` | 720 px |
| `xl` (реестры, просмотр благодарностей) | 1120 px |

`dialog`: `max-height: 90vh`, `overflow-y:auto`, `radius-lg`, `blur-modal`, `shadow-2xl`,
анимация `modalIn 280ms ease-overlay`.
Секции: `head` (24 px, заголовок 17/700 + кнопка-крестик) · `body` (22 24 px, `gap: space-4.5`)
· `foot` (18 24 px, кнопки справа, `gap: space-3`).

**[Светлая]** Scrim `rgba(12,30,23,.45)` — зеленовато-тёмный, а не чёрный: под ним светлая
страница не сереет, а уходит в тон бренда. Это один из немногих случаев, где `shadow-2xl`
уместен на светлом фоне: модалка обязана «оторваться» от почти такой же белой страницы.

**Состояния:** открытие — `modalIn`; закрытие — по крестику, клику на scrim и `Esc`;
`error` — блок `.errmsg` над подвалом; `loading` — кнопка подтверждения в состоянии `loading`.

**Do's:** фокус при открытии — на первое поле; заголовок дублирует действие пользователя.
**Don'ts:** не открывать модалку из модалки; не размещать в модалке таблицу шире `xl`.

| Компонент | Форма | Размер | Состав |
|---|---|---|---|
| `status` | пилюля `radius-full` | 4 10 px, 11 px/600 | точка 6 px + подпись |
| `tag` | `radius-xs` | 2 8 px, 11 px/600 | подпись, тонкая граница |
| `chip` | `radius-xs` | 2 6 px, 11 px/700 | иконка + число |
| `counter` | круг 15–16 px | 9.5 px/800 | число, фон `--color-error` |
| `medal` | круг 23 px | 11 px/800 | номер места, металлический градиент |
| `ribbon` | полоса на всю ширину карточки | 22 px, 9.5 px/800 UPPERCASE | «1 место» |

**Карта статусов заявки**

| Статус | Класс | Цвет | Подпись в светлой теме |
|---|---|---|---|
| В ожидании | `rev` | warning | `#d97706` — 2.97:1, набирать 11 px/600 **нельзя**: либо `#b45309`, либо 14 px/700 |
| На доработке | `rev` | warning | то же |
| Отозвано | `info` | info | `#0284c7` — 3.67:1, от 14 px/700 |
| Отправлено | `ok` | success | `#059669` — 3.42:1, рекомендуется `#047857` |

**[Светлая]** Статусы набираются 11 px/600 — это обычный текст, порог 4.5:1. Значит для
светлой темы либо применяются заменённые ступени из §1.8, либо кегль поднимается до 14 px/700.
`medal` со ступенью `-100` на белом требует обводки (§1.1).

**Do's:** статус всегда = точка + текст. **Don'ts:** не кодировать статус только цветом;
не использовать более одного `counter` на элемент.

## 2.6. Navigation

### Sidebar
`width: 260px` → `76px` (collapsed). Состав: кнопка сворачивания → логотип-блок →
список пунктов → подвал (переключатель темы + карточка профиля).

**Пункт (`nav-item`):** высота 40 px, `radius-md`, `gap: space-2.5`, иконка в круге 22 px
(`--color-success-soft` / `--color-success-text`), подпись 12 px/500.

| Состояние | Стиль |
|---|---|
| `default` | текст `--color-text-muted` |
| `hover` | фон `--color-row-hover`, текст `--color-text` |
| `active` | фон градиента действия, текст `#fff`/700, тень `0 6px 18px -6px rgba(10,92,64,.75)`, бегущий блик |
| `group` | справа стрелка, поворот на 90° при раскрытии |
| `child` | отступ слева 18 px, точка-маркер 6 px, вертикальная линия-связка |
| `collapsed` | 44 × 44 px, только иконка, **строго по центру** — включая пункт-группу |

**[Светлая]** `hover` меняет фон с `#fff` на `#f7faf8` — разница 3 %. Чтобы состояние читалось,
одновременно с фоном меняется цвет текста `muted → text`; только фоном ограничиваться нельзя.
Подпись активного пункта белая 12 px/700 на градиенте действия — вес 700 обязателен.

### Top bar
«Стеклянная таблетка»: высота 56 px, `radius-full`, фирменный градиент + внутренние блики,
`blur-bar`. Слева поиск, справа — кнопка наград, разделитель, профиль, уведомления,
разделитель, язык, выход. Разделитель — вертикальная светящаяся линия 1.5 px.
Прилипание: `position:sticky; top:0; z-index:30`, при скролле добавляется `blur-dock` и тень.

**[Светлая]** Панель остаётся тёмно-градиентной — это третий «тёмный островок» светлой темы
и главный якорь фирменного стиля на странице. Все её внутренние элементы (поиск, иконки,
разделители) считаются элементами тёмной темы: белый текст, полупрозрачные белые подложки.

### Tabs
Контейнер `radius-sm`, фон `--color-surface-2`, padding 2 px. Вкладка: 6 12 px, 12 px/600,
активная — белый текст на градиенте с анимацией `scaleIn`. На градиентной шапке —
полупрозрачный белый вариант (`glass tabs`).

### Breadcrumbs
11 px/500, `--color-text-faint`, разделитель `/`, последний элемент — `<b>` цветом `--brand-1`.
**[Светлая]** `text-faint` даёт 2.64:1 — для крошек это допустимо только потому, что путь
дублируется заголовком страницы; если крошки единственный указатель раздела, брать `text-muted`.

## 2.7. Table

**Анатомия:** `table-card` → `table-head` (заголовок + подпись + инструменты) →
`filters` (опционально) → `table-scroll` → `table` → `footer` («Показано 1 – N из M записей»).

| Элемент | Стиль |
|---|---|
| `thead tr` | фон `--color-surface-2`, границы сверху и снизу 1 px |
| `th` | 10 px/700, UPPERCASE, `letter-spacing .05em`, `--color-text-faint`, padding 10 20 px, `white-space:nowrap` |
| `td` | 13 px, padding 14 20 px, `vertical-align:middle` |
| `tbody tr` | `border-bottom: 1px solid --color-line`, `transition: background 150ms` |
| `tr:hover` | `background: --color-row-hover` |
| `tr.selected` | `background: --color-success-soft` |
| `tr.muted` (без данных) | `opacity: .62` |
| `.empty` | 40 20 px, по центру, 13 px, `--color-text-faint` |
| `td.link` | `cursor:pointer`, hover — `--color-success-text` + подчёркивание |
| сортировка | стрелка `⇅ / ▲ / ▼` в `th.sortable` |

Таблице задаётся `min-width`, обёртке — `overflow-x:auto`.

**[Светлая]** Три замечания:

1. `th` цветом `--color-text-faint` — 2.51:1 на `surface-2`. Шапка таблицы это структурная
   информация, поэтому в светлой теме `th` берёт `--color-text-muted` (4.93:1).
2. `tr:hover` `#fff → #f7faf8` — почти невидимо. К смене фона добавляется левая полоса
   `inset 2px 0 0 var(--color-primary-500)` либо усиление границы строки.
3. `tr.muted` при `opacity:.62` на белом теряется полностью — в светлой теме `.75`.

**Do's:** числовые колонки — `font-variant-numeric: tabular-nums`, выравнивание по центру или
вправо; действия — последняя колонка фиксированной ширины.
**Don'ts:** не более одной интерактивной колонки-ссылки в строке; не прятать важные колонки
за горизонтальный скролл без явного индикатора.

## 4.3. Переключение темы

```js
// светлая — состояние по умолчанию; класс 'dark' только добавляется
const KEY = 'nbrk-theme';

function applyTheme(mode) {              // mode: 'light' | 'dark'
  document.documentElement.classList.toggle('dark', mode === 'dark');
  try { localStorage.setItem(KEY, mode); } catch (e) {}
}

function initTheme() {
  let saved = null;
  try { saved = localStorage.getItem(KEY); } catch (e) {}
  if (saved) return applyTheme(saved);
  // без сохранённого выбора — идём за системной настройкой
  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  applyTheme(prefersDark ? 'dark' : 'light');
}

initTheme();
```

**Важно:** `initTheme()` вызывается синхронно в `<head>` до отрисовки body — иначе при
сохранённой тёмной теме страница успевает мигнуть белым.

# 5. ГОТОВНОСТЬ И СЛЕДУЮЩИЕ ШАГИ

Система собрана по фактическому коду прототипа, дополнительные файлы не требуются.
Что можно доработать по вашему решению:

1. **Компонентная библиотека** — вынести §2 в React-компоненты с типизированными пропсами
   (`<Button variant size state>`, `<Field type error>`, `<DataTable columns rows>`).
2. **Figma Tokens** — импортировать §3 напрямую; названия слоёв уже соответствуют токенам.
   Блок `color.a11y` подключить как отдельный набор «AA overrides».
3. **Контраст — требует решения.** Четыре пары не проходят AA (§1.8): `text-faint` на обеих
   светлых поверхностях (2.64:1 и 2.51:1), `warning-text` на своей подложке (2.97:1),
   плюс две пары держатся только на AA Large — `success-text` (3.42:1) и белый на
   `primary-500` (3.30:1). Возможны два пути:
   **(а)** заменить токены на значения из блока `a11y` — правка чисто в CSS-переменных,
   визуально почти незаметна;
   **(б)** оставить палитру и поднять кегль/вес в местах применения до 14 px / 700.
   Рекомендуется **(а)** для `text-faint` и `warning-text`, **(б)** для белого на бренде,
   чтобы не менять фирменный цвет кнопок.
4. **Локализация** — интерфейс русскоязычный, справочники двуязычные (KZ/RU); при вводе
   казахской локали типографическая шкала не меняется, но нужен запас ширины ~15 % в кнопках и метках.
5. **Печать** — светлая тема даёт готовую основу для `@media print`: достаточно убрать
   градиентные острова (топбар, стеклянные виджеты) и тени, границы уже несут структуру.
