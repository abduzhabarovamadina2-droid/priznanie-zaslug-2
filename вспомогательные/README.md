# Вспомогательные материалы

Здесь лежит то, что нужно для истории и разовых задач, но не входит
в рабочее приложение. Ничего отсюда не требуется для запуска
`frontend/`, `backend/` или `deploy/`.

| Папка | Что внутри |
|---|---|
| `прототипы-история/` | `PREV*.html` и резервные копии прототипа. Историю теперь ведёт Git, папка оставлена для сверки |
| `доп варианты/` | ранние варианты вёрстки модуля |
| `дизайн-система/` | UI Design System: светлая и тёмная темы, HTML и Markdown |
| `скрипты-правки/` | `fix-*.ps1` — разовые PowerShell-правки прототипа, `photo200.ps1` — сжатие фотографий до 200×200 |
| `исходные-данные/` | `Сотрудники.xlsx`, `Рейтинг.xlsx` — источники для JSON, и прежние версии JSON |
| `backend-TEST/` | копия backend под тестовую базу (порт 4001). Код совпадает с `backend/`; отличаются только `.env` и отладочные скрипты |
| `прочее/` | ярлыки, временные файлы Office, старые логи |

## Про `backend-TEST/`

Копия появилась, чтобы работать с тестовой базой, не трогая основную.
Дублировать код для этого не нужно: достаточно второго файла окружения —
`backend/.env.test` с другими `DATABASE_URL` и `PORT` — и запуска

```powershell
cd backend
node -r dotenv/config src/server.js dotenv_config_path=.env.test
```

Папка оставлена как есть, пока в ней есть надобность; при следующей
правке backend её лучше удалить, чтобы не разъезжались две копии кода.
